# مكتب صفر — موقع الكاتب يوسف طلب

موقع ثابت (Static Site) لعرض كتب المؤلف وقراءتها مباشرة كملفات PDF داخل المتصفح.

## هيكل المشروع

```
maktab-sifr/
├── index.html              الصفحة الرئيسية (شبكة الكتب)
├── book.html                صفحة قراءة كتاب واحد
├── static/
│   ├── css/style.css        كل التنسيقات (الألوان الفرعونية + الخطوط)
│   ├── js/books-data.js     قائمة الكتب (العنوان، الوصف، مسار الغلاف، مسار PDF)
│   ├── images/               أغلفة الكتب (SVG) — استبدلها بأغلفة حقيقية
│   └── pdfs/                 ملفات الكتب الفعلية (PDF) — استبدلها بالنسخ الحقيقية
```

## إضافة كتاب جديد أو تعديل كتاب موجود

1. ضع غلاف الكتاب في `static/images/` (jpg أو png أو svg).
2. ضع ملف الكتاب في `static/pdfs/` بصيغة PDF.
3. افتح `static/js/books-data.js` وأضف عنصرًا جديدًا في مصفوفة `BOOKS`:

```js
{
  id: "unique-id",          // معرّف فريد بالإنجليزية بدون مسافات
  title: "عنوان الكتاب",
  subtitle: "رواية",
  description: "وصف قصير للكتاب.",
  cover: "static/images/cover.jpg",
  pdf: "static/pdfs/book.pdf",
  accent: "gold"            // gold أو turquoise أو terracotta (لون التمييز فقط، اختياري)
}
```

لا حاجة لتعديل أي HTML — الصفحة الرئيسية وصفحة القراءة تُبنيان تلقائيًا من هذه القائمة.

## التشغيل محليًا

الموقع ثابت بالكامل (HTML/CSS/JS بدون خادم). لتشغيله محليًا افتح `index.html` مباشرة
في المتصفح، أو شغّل خادمًا بسيطًا من داخل مجلد المشروع لتفادي أي قيود على فتح
ملفات PDF محليًا في بعض المتصفحات:

```
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000` في المتصفح.

## ملاحظات

- الأغلفة الحالية (`static/images/book-1.svg` ... `book-6.svg`) وملفات PDF
  (`static/pdfs/book-1.pdf` ... `book-6.pdf`) هي عناصر بديلة (placeholders)
  لتوضيح الشكل والبنية — استبدلها بالأعمال الحقيقية بنفس الأسماء أو بأسماء
  جديدة (مع تحديث `books-data.js`).
- قراءة الكتاب تتم عبر عرض ملف الـ PDF مباشرة داخل الصفحة (iframe)، مع زر
  لتحميل الملف وزر لفتحه في تبويب مستقل.
